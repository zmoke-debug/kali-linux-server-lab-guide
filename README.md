- 使用 `vsftpd` 搭建和测试 FTP 服务器
- 匿名用户与本地用户访问配置
- 防火墙、日志、端口和连接测试
- 使用 Tomcat 搭建 Web 服务器
- 使用 Flask 搭建 Web 服务
- 实验过程中的常见问题与安全建议

## 使用说明

1. 建议在 VMware、VirtualBox 或其他隔离的 Kali Linux 虚拟机中操作。
2. 文档中的软件版本、镜像地址和配置项可能会随 Kali Linux 更新而变化，请以当前官方文档为准。
3. 文档中的账号和密码仅用于演示，禁止在真实环境中复用。
4. FTP 明文传输和匿名写入存在明显安全风险。实验完成后应关闭服务；实际环境优先使用 SFTP 或 FTPS。
5. 不要把实验服务直接暴露到公网。
